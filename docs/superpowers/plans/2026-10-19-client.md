# SteadyType Client Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the wxPython desktop client: sign in, speak a lesson through Prism, play the cues, take the whole keyboard, and save attempts locally.

**Architecture:** wxPython draws only native controls. A pure presenter translates engine commands into speech, sound, and display calls, so the teaching flow is tested without a window or a reader. Speech goes through Prism; sounds come from `assets/sounds`; attempts and accounts live in a local SQLite file until Plan 3 adds the server.

**Tech Stack:** Python 3.13, wxPython 4.3.2, prismatoid, SQLite (stdlib), pytest.

**Spec:** `docs/superpowers/specs/2026-10-19-steadytype-design.md`

**This is plan 2 of 3.** Plan 3 adds the FastAPI server, dashboard, and sync.

## Global Constraints

- Native wx controls only: `TextCtrl`, `Button`, `CheckBox`, `RadioButton`, `Choice`, `ListBox`, `Menu`, `Frame`, `Dialog`. No `TreeCtrl`, no `DataViewCtrl`, no custom-drawn buttons.
- The lesson surface is the only custom-drawn control and exposes no accessible children.
- One voice per event: a focused native control is announced by the reader; lesson content is spoken only through Prism.
- Every user-facing string is spoken text: plain words, no jokes, no abbreviations a reader would mangle.
- All colours meet 4.5:1 for text and 3:1 for indicators. Meaning never depends on colour alone.
- The keyboard is captured only while a lesson runs, and released by Escape three times or Control Alt Shift X.
- Tests that need a window are marked `@pytest.mark.ui` and skipped unless `STEADYTYPE_UI=1`.
- The client imports the engine; the engine never imports the client.

## Review Focus

1. A reader is running and Prism cannot find a backend. Sign-in and the menus must still work, and the failure must be spoken in plain words, not a traceback.
2. The keyboard hook fails to install, or the lesson window loses focus mid-task. Capture must fall back to window-only input, say so, and never leave the keyboard swallowed.
3. Escape is pressed once during a lesson. It must not quit, stop the lesson, or release capture; only the third press within the window does.
4. A student signs in on a shared machine with "remember username" only. No password or token may be written to disk in plain text.
5. The lesson surface gains focus while a reader is running. The reader must not announce the lesson text that Prism is already speaking.

### Task 5: Lesson presenter

**Files:**
- Create: `client/src/steadytype_client/presenter.py`
- Test: `client/tests/test_presenter.py`

**Interfaces:**
- Consumes: `LessonSession`, `result_commands`, `PracticeClock` from the engine; `SpeechEngine`; `SoundPlayer`.
- Produces: `LessonPresenter(lesson, prefs, goals, speech, player, clock, save=None, now=time.monotonic)` with `start()`, `handle(event)`, `tick()`, `repeat()`, `state`, `position`, `message`; `DisplayPort` protocol with `show(text: str, position: int)`.
- Rule: a `Tone` command plays the sound only when `prefs.tones` is true. A `Speak` command always goes to speech. At the end, `result_commands` are spoken and the engine's attempt is passed to `save`.

- [ ] **Step 1: Write the failing tests**

```python
from steadytype_engine.lesson import Lesson
from steadytype_engine.preferences import Preferences
from steadytype_engine.scoring import Goals

from steadytype_client.presenter import LessonPresenter
from steadytype_client.sounds import NullPlayer
from steadytype_client.speech import FakeSpeech

LESSON = Lesson.from_dict({
    "schema": 1, "id": 1, "unit": 1, "ordinal": 1, "title": "T",
    "teaches": ["a"], "kind": "keyboarding", "end_key": "space",
    "repeat": 2, "intro": "Type a.", "tasks": [{"text": "a"}],
})


def make():
    speech, player, saved = FakeSpeech(), NullPlayer(), []
    presenter = LessonPresenter(LESSON, Preferences(), Goals(), speech, player,
                                save=saved.append)
    return presenter, speech, player, saved


def test_speech_goes_to_the_engine_and_tones_to_the_player():
    presenter, speech, player, _ = make()
    presenter.start()
    assert speech.spoken[0][0] == "Type a."
    presenter.handle(_key("a"))
    assert "correct" in player.played


def test_tones_off_means_no_sound():
    presenter, speech, player, _ = make()
    presenter = LessonPresenter(LESSON, Preferences(tones=False), Goals(), speech,
                                player, save=lambda record: None)
    presenter.start()
    presenter.handle(_key("a"))
    assert player.played == []


def test_finishing_saves_one_attempt_and_speaks_the_result():
    presenter, speech, _, saved = make()
    presenter.start()
    for _ in range(2):
        presenter.handle(_key("a"))
        presenter.handle(_key(" "))
    assert len(saved) == 1
    assert any("accuracy" in text for text, _ in speech.spoken)
```

- [ ] **Step 3: Implement**

from steadytype_engine.keys import Key, KeyEvent, Side


def press(key, clock):
    return KeyEvent(kind="down", key=key, text=None, modifiers=frozenset(),
                    side=Side.NONE, is_repeat=False, scan_code=0,
                    timestamp=clock[0])


def test_two_f2_presses_mean_next():
    clock = [0.0]
    router = CommandRouter(now=lambda: clock[0])
    assert router.feed(press(Key.F2, clock)) is None
    clock[0] = 0.2
    assert router.feed(press(Key.F2, clock)) == "next"

    router = CommandRouter(now=lambda: clock[0])
