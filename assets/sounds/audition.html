SteadyType sound cues

Each cue has two versions. The first is the clean synthesized tone. The second was generated with Stable Audio on this machine. Play both and tell me which set to use.

The synthesized set is the default because every cue is under 600 milliseconds, which is what a lesson needs. Some model cues run over a second, so a wrong key would leave the student waiting. Individual model cues can still be swapped in where they are short enough.

Cues

  • Correct key (correct)
  • Wrong key (wrong)
  • Race start (race_start)
  • Ten seconds left (race_warning)
  • Race end (race_end)
  • Lesson finished (lesson_done)
  • Practice goal reached (goal_reached)
